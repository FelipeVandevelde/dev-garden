# Static Sites

Rendering every page at build time keeps a site fast, cheap to host and easy to cache. Interactive parts, like the knowledge graph or the command palette, load as small islands on top of plain HTML.

The trade-off is freshness: content only changes when the site rebuilds. Here, pushing a note to the vault triggers a new build, so the garden stays current without a server.
