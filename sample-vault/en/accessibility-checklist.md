# Accessibility Checklist

- Text keeps a contrast ratio of at least 7:1 (WCAG AAA).
- Every interactive element is reachable by keyboard and shows a visible focus state.
- Animations respect `prefers-reduced-motion`.
- Images have alt text; decorative images have an empty one.

> [!warning] Work in progress
> This list is still a sprout. It grows each time an audit finds a new gap.
