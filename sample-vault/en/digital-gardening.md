# Digital Gardening

A digital garden is a set of notes that grow over time, instead of a feed of finished posts. Every note carries a maturity status:

- **sprout**: a rough idea, written down before it is lost
- **growing**: being worked on and linked to other notes
- **evergreen**: stable, reviewed, and safe to link from anywhere

> [!tip] Start small
> One honest paragraph is enough for a sprout. Link it to something you already wrote and let it grow.

This garden is built with [[Static Sites|static site generation]], and every page follows the [[Accessibility Checklist]]. For the note format itself, see [[Writing Notes]].
