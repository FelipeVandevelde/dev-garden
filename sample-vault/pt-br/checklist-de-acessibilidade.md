# Checklist de Acessibilidade

- O texto mantém contraste de pelo menos 7:1 (WCAG AAA).
- Todo elemento interativo é acessível pelo teclado e mostra um foco visível.
- As animações respeitam `prefers-reduced-motion`.
- Imagens têm texto alternativo; imagens decorativas têm um vazio.

> [!warning] Em construção
> Esta lista ainda é um broto. Ela cresce a cada auditoria que encontra uma nova falha.
