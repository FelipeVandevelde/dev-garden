# Sites Estáticos

Gerar todas as páginas no build deixa o site rápido, barato de hospedar e fácil de cachear. As partes interativas, como o grafo de conhecimento ou a paleta de comandos, carregam como pequenas ilhas sobre HTML simples.

A contrapartida é a atualização: o conteúdo só muda quando o site é reconstruído. Aqui, enviar uma nota ao vault dispara um novo build, então o jardim fica em dia sem precisar de servidor.
